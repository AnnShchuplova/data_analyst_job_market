# Кластеризация

## ⚙️ Архитектура



**1. Data Loading (`src/utils/data_loader.py`)**

* Ищет последний файл `new_cleaned_vacancies*.csv` в `data/processed`.

* Если запущено в `.exe`, корректно определяет пути внутри временной папки `_MEIPASS`.



**2. Clustering Logic (`src/services/clustering_service.py`)**

Сервис автоматически выбирает алгоритм в зависимости от выбранных пользователем признаков:

 - **Только числа** (ЗП, Опыт) → **K-Means** (Euclidean distance).

 - **Только категории** (График, Город) → **K-Modes** (Hamming distance).

 - **Смешанные данные** → **K-Prototypes**.

&nbsp;    Использует **матрицу Гауера** (Gower Distance) для точного расчета метрик на смешанных данных.

&nbsp;    Сканирует диапазон кластеров (Range 2-20) и выбирает лучший по метрике **Silhouette Score**.



**3. Interpretation (`src/domain/models.py`)**

После формирования кластеров сервис генерирует мета-данные:

 - **Название:** Если имя вакансии встречается у >30% группы, оно выносится в заголовок.

 - **Тег ЗП:** Сравнивает медиану кластера с 30% и 70% квантилями всего рынка (Маленькая / Нормальная / Высокая).

 - **Skills:** Парсит списки навыков и выводит топ-5 популярных в кластере.

 - **Remote:** Считает процент удаленной работы по ключевым словам.



**4. UI (`app/views/clusters.py`)**

* Интерфейс на **Streamlit**.

* Кэширование данных через `@st.cache_resource`.

* Визуализация: карточки с метриками, HTML-шкала (Офис/Удаленка), цветные теги навыков.
