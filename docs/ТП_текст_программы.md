```
                      4
          RU.17701729.11.03-01 12 01-1
            1. ОБЩИЕ СВЕДЕНИЯ

1.1. Назначение документа

     Документ устанавливает состав исходных программных
     модулей, язык их реализации и местонахождение в системе
     контроля версий.

1.2. Местонахождение текстов программы

     Полные актуальные тексты всех программных модулей,
     входящих в состав системы DataTrack, размещены в
     общедоступном репозитории системы контроля версий Git
     по следующему адресу:

         https://github.com/AnnShchuplova/data_analyst_job_market

     Доступ: открытый (public repository).
     Платформа: GitHub (Microsoft Corporation).
     Основная ветка: main.

     Для получения локальной копии исходных текстов
     необходимо выполнить команду:

         git clone https://github.com/AnnShchuplova/data_analyst_job_market.git

     Фиксация (commit), соответствующая версии настоящего
     документа, идентифицируется по тегу или хеш-сумме
     последнего коммита ветки main на дату утверждения
     документа.

1.3. Язык программирования

     Все программные модули системы написаны на языке
     Python версии 3.11 и выше.
     Стандарт кодирования: UTF-8 (без BOM).
     Стиль оформления кода: PEP 8.

1.4. Операционная среда

     Программа функционирует под управлением ОС Linux
     (в контейнерной среде Docker) и Windows 10/11
     при локальном запуске. Совместимость обеспечивается
     через виртуальное окружение Python (venv / pip).
```
